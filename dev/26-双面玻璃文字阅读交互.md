# 双面玻璃文字阅读交互

2026-11-22，延续已认领 Issue #37。用户选择保留翻面和灯光跟随，移除圆形放大镜，改为类似 Mac Dock 的文字临近放大；正反两面一致。仅本地审阅，不提交上传。

## 原因与设计

已在浏览器复现：正面有 1 个阅读组件，背面为静态文本，没有阅读组件（0 个），因此行为不一致。旧交互复制原文到圆形镜片，属于独立的取样工具，和用户期待的原位文字反馈不同；继续调整光圈大小不能解决这个差异。

沿用烟灰玻璃与六色系统：#090a0f、#f2f2f8、#b3b3c5、#c8b6ff、#ffffff24、#d5c9f9。字体 Segoe UI / Microsoft YaHei UI。字号增至正文 14px、标题 23px；长句允许自然换行。

```text
原文正面：灯光随鼠标移动 + 靠近的词轻微放大、上浮、玻璃高光
       ↕ 翻面（保留原过渡）
分析背面：相同的词级阅读反馈 + 同一光场
```

文字使用分词后的原位元素，指针附近的词形成柔和放大曲线，邻近词反馈递减。最大放大约 1.12，抬起约 2px，不改变字距或布局；只做 transform 和玻璃文字高光。没有圆形光圈、文字副本或遮罩。

性能：鼠标坐标存 refs，用 requestAnimationFrame 合并输入；读取静态词框后统一写样式，指针帧内不读变换后的词框；两面共用组件。灯光恢复在阅读区域跟随，使用小范围、低强度的反射层，避免叠加圆形放大镜。

无障碍：完整连续原文给辅助技术，视觉分词层不拆成多个朗读节点；方向键聚焦词语，Enter 翻面、Escape 复原；触屏点击文字给反馈，原文入口与翻面仍为按钮。减少动态效果时取消缩放和抬起，仅保留轻微高光。

技能依据：ui-ux-pro-max 的 UX 检索命中 reduced-motion、hover-vs-tap；React 高频交互按 vercel-react-best-practices 的 rerender-use-ref-transient-values 与 js-batch-dom-css。保持既有视觉语言，不引入新的动画库。具体参数需要浏览器自审后定稿。

## 完成内容与自审

- 正反面均使用 GlassReader，同一套分词、邻近反馈、键盘逻辑。浏览器复测两面各有 1 个阅读组件。
- 移除圆形镜片、复制文字、取样坐标模块及旧测试。中文/英文分词后保持原文标点、换行、内容完全一致，辅助技术读取连续文本，视觉分词层 aria-hidden。
- 以词为单位形成连续邻近曲线，桌面最终最大 1.10 倍、上浮 2px；窄屏最大 1.08 倍、上浮 1px。采用原位 transform，周围布局不重排，130ms 小幅反馈过渡；离开、Escape、翻面或切换片段复原。
- 自审去除了逐词小玻璃框，避免碎片感。字面用明亮填充、上缘亮边、下缘暗部和细微反射表达玻璃；保留清晰文字，未使用透明字面。
- 跟随灯光恢复到整个玻璃面板，包括两面的阅读区域。把原来的渐变位置绘制改成固定径向反射层平移，requestAnimationFrame 合并最新坐标，保留柔光与材质感。
- 词框读取使用静态 offset，先读后写；鼠标位置、当前强度、布局缓存均存 refs。指针移动不触发 React 重渲染，变动低于阈值时跳过样式写入。滚动、缩放、字体加载完成时使缓存失效。
- 翻面过渡、完整原文弹层、来源版本/行号保留。按钮最小高度在手机为 44px；减少动态效果时移除抬起/缩放与跟随灯光，保留文字高光。

## 验证结果

- `cd frontend && npm run typecheck && npm run build && npm run format:check`：通过。61 个模块，CSS 75.01 kB、JS 342.72 kB。
- `node --test scripts/test_frontend_workspace.mjs scripts/test_frontend_knowledge.mjs scripts/test_frontend_events.mjs`：16 项通过，包含新的原文分词完整性与连续衰减边界检查。
- `git diff --check`：通过。
- 桌面实际鼠标操作：正面“归还”词强度 0.996、缩放 1.0996、上浮约 1.99px；相邻词强度降低。背面“测量”强度 0.999、缩放 1.0999、上浮约 2px。灯光平移坐标随鼠标改变，圆形镜片数量为 0。
- 背面键盘方向键反馈、Escape 复原与前面 inert 隔离均检查。原文弹层 Tab 边界循环与 Escape 关闭可用；确认弹层关闭完成后翻回按钮正常。
- 375px 手机、320px 窄屏、812×375 横屏：无横向溢出，原文正文与底部来源信息不相撞。手机“实践”实际缩放 1.08、上浮 1px。临时视口已恢复并保留默认首页预览。

验证边界：未使用真实手机硬件；系统减少动态效果、最大系统字号仅检查源码，本轮未更改系统设置验证。未采集精确 FPS/GPU 帧时间，不保证所有设备帧率；本机实际手感由用户继续预览确认。真实后端联调不在本轮范围。
