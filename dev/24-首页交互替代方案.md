# 首页交互替代方案

2026-11-22，延续已认领 Issue #37。用户反馈点阵与倾斜的“原文证据 / 下一步行动”难以理解，授权优化并提供其他交互。本轮继续本地预览，不提交、推送。

## 实现前设计

移除整个点阵、景深轨道和装饰性流程文字；首页展示对象改为实际合成项目中的原文片段。保留午夜玻璃配色：夜幕 #090a0f、银白 #f2f2f8、次级 #b3b3c5、雾紫 #c8b6ff、描边 #ffffff24。字体继续 Segoe UI / Microsoft YaHei UI，主卡片内容横向排版；只给操作反馈添加动效，不自动播放。

- A 叠片翻阅（推荐）：把合成项目片段做成可翻阅的玻璃文档；点击片段标签切换，点击主卡片打开原文。含义是“翻阅资料”，不用理解抽象空间。
- B 对照揭示：一边是原文，一边是分析结论；拖动分隔线查看关联。原生 range 支持触屏和键盘。明确“这句话为什么能支持结论”。
- C 聚光阅读：在真实横排文字上移动放大镜；鼠标/触屏/方向键均有操作方式，完整原文仍可直接打开。玻璃和特写服务于阅读。

```text
短标题与主入口 │ 合成项目原文 / 一种可理解的交互
                 项目片段选择 + 打开原文
开发对比条：A 叠片翻阅 | B 对照揭示 | C 聚光阅读
```

自审：不再把流程名称悬浮在装饰画面里；三个方案分别对应翻阅、对照、放大三种熟悉的动作。默认页采用 A，只有开发模式显式 `?hero=` 时展示比较条，避免正式首页增加设计设置。原文对话框、Escape、焦点循环和关闭后焦点恢复沿用并复测。

用户进一步澄清：以最初 C 概念图的可见玻璃质感为准，“增加透明度”不是让面板消失，而是强调光泽、厚度、反光与顺滑度。据此提高主玻璃的烟灰填充与内侧反射，增加双层边缘和局部镜面反光；背景大玻璃曲面只作材质陪衬，不放流程文字。交互使用随指针改变的反光和文档切换，不做全卡片文字倾斜。工作区只在上传区、选中原文和主要操作上加强同样材质，不把长文本区域变成高光背景。

自审调整：文字对照使用拖动遮罩会截断句子，B 改为“翻面核对”：同一张玻璃卡片正面是原文，背面是对应分析，点击或 Enter 翻面；文字始终完整横排，也更符合用户补充的顺滑玻璃交互。

## 完成内容

- 点阵、景深轨道、悬浮流程文字与仅切换装饰的三段按钮已移除，也清理了对应 CSS。
- 主玻璃采用烟灰填充、双层细边、内侧高光与暗边；大曲面玻璃作为背景层。鼠标只改变镜面反射位置，不旋转正文。反光用已注册的 CSS 自定义属性做平滑过渡，减少生硬跳变。
- A 默认叠片：真实合成片段横排、玻璃文档分层，悬停抬起、按压回弹，切换内容时短距离淡入；点击卡片打开当前片段。不再重复放第二个打开按钮。
- B 翻面：680ms 过渡，正反两面分别显示原文与对应的合成分析；点击或 Enter 操作，切换项目片段会返回正面。
- C 聚光：可读原文上的玻璃放大镜，局部 1.14 倍放大、光学边缘与反射；鼠标移动/触屏轻点定位，方向键每次移动 8%，100ms 平滑跟随。完整原文仍有直接入口。
- 工作区上传框、原文侧栏、原文弹层同步增强玻璃边缘和反射，正文保留稳定深色底。
- 默认首页只展示 A；开发模式 `?hero=stack|reveal|focus` 显示三个方案的切换条。生产模式不显示设计设置。
