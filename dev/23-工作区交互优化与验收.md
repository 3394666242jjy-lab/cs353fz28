# 工作区交互优化

2026-11-22，延续已认领的前端设计 Issue #37。用户授权完善上传反馈、主操作层级、结论与原文联动；本地审阅后才提交或推送。

## 设计计划

沿用午夜玻璃：夜幕 #090a0f、银白 #f2f2f8、次级 #b3b3c5、雾紫 #c8b6ff、描边 #ffffff24。字体保持 Segoe UI / Microsoft YaHei UI。工作区标题 28px、正文 14px、操作说明 12px，内容左对齐。

资料区用真实状态展示“上传 / 解析 / 可使用”，拖入时仅高亮落点，拒绝错误类型、多文件与超限文件；传输失败保留文件重试，解析失败使用现有重建索引接口，不重复上传。上传状态不伪造百分比。

岗位页只突出当前需要的动作，样例入口降为次要；真实分析前就近列出缺少条件，并可直接去登录、选择资料或修改岗位。

```text
分析结果：结论列表（当前引用高亮） │ 原文侧栏（文件、版本、定位、引用高亮）
窄屏：原文置于列表前，打开时定位；“返回对应结论”恢复引用按钮焦点
```

自审：不新增装饰性统计或流程面板；动效只响应拖入、选择与打开原文。原文只展示接口返回的实际片段，不虚构上下文或行号；样例与真实分析复用一个组件，统一错误、取消、重试和键盘行为。

## 已实现

- 上传区：文件拖入高亮、文件类型/大小/空文件校验、传输中锁定文件与资料类型、失败保留文件并提供重试；请求超过 60 秒给出失败反馈。每份资料显示已上传、解析、可使用的实际阶段，不展示估算百分比。
- 解析失败：读取当前版本后调用现有 reindex 接口，等待返回的执行任务结束再确认资料状态，避免任务刚入队时把旧的 failed 状态当成新失败。不重复上传原文件。
- 资料衔接：可使用资料提供“继续，填写目标岗位”；上方上传列表状态变化会刷新下方资料库，保留正在编辑的正文。
- 主操作：岗位页聚焦保存，样例入口降级；分析移到匹配分析页。未登录、无可用资料、岗位未填写/未保存/有修改分别提供就近修复入口；样例模式不需要这些真实分析条件。结果完成后“重新分析”为次要操作，“生成准备计划”放在结果下方。
- 原文联动：真实与样例分析复用 AnalysisResults；选中结论高亮，桌面侧栏保留结论上下文、文件、版本、实际行号或页码和高亮引用。原文加载失败可独立重试；切换引用/关闭时取消旧请求，迟到响应不能覆盖新选择。
- 窄屏：原文排到结论列表前，异步加载完成后保持标题在视野内；返回按钮或 Escape 恢复对应引用按钮焦点。
- 一并修复：刷新时恢复已保存的岗位名称和 JD；本地样例岗位可另存为真实岗位；分析等待条使用不定进度，不再按耗时推算完成比例。

## 验证结果

2026-11-22 完成：

- `cd frontend && npm run typecheck`：通过。
- `cd frontend && npm run build`：通过（构建包含类型检查）；59 个模块，CSS 70.40 kB、JS 约 339.68 kB。
- `cd frontend && npm run format:check`：通过。
- `node --test scripts/test_frontend_workspace.mjs scripts/test_frontend_knowledge.mjs scripts/test_frontend_events.mjs`：14 项全部通过。其中新增 5 项覆盖前置条件、同资料/版本重试和引用版本与取消信号。
- `git diff --check`：通过。

浏览器使用独立的本地合成服务（8011）与验收前端（5175），没有使用真实账号、文件或数据库。人工走通：

1. 缺少分析条件时按钮禁用，登录、资料与岗位入口可用；用合成账号和资料填完条件后可开始分析。
2. 实际文件选择器选择合成 Markdown → 首次上传失败 → 文件保留 → 重试成功 → 等待解析/可使用 → 两处列表自动同步。SVG 在选择后被拦截，不出现上传按钮。
3. 解析失败 → 重试 → 后端旧 failed 状态仍保留时前端持续等待新执行 → 可使用。
4. 保存岗位 → 前往分析 → 等待 → 显示结果；刷新后岗位正文、版本与分析恢复。
5. 引用首次请求失败 → 侧栏独立重试成功；切换第二条引用显示第 15–16 行；Escape 关闭后焦点返回第二条引用，展开状态清除。
6. 1440px 桌面左右对照、391px 手机与 320px 窄屏无横向溢出；手机异步加载后原文标题距视口顶部 24px，返回结论位置与焦点正确。临时视口已恢复。
7. 实际项目 5174 上的完整合成示例使用同一联动组件，已打开并保留预览。

未验证项：真实后端链路、实际网络传输进度与真实图片 PDF 解析不在本轮验证范围。文件拖放高亮、超限与空文件校验、reduced-motion 分支已检查源码，未在浏览器完成原生拖放、超限/空文件和系统减少动态效果的实际操作验证。原文高亮只覆盖接口返回的引用片段，不代表完整文档全文定位。
