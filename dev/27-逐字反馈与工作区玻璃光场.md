# 逐字反馈与工作区玻璃光场

2026-11-23，延续已认领 Issue #37，仅本地修改供用户审阅，不暂存、提交或推送。

## 设计范围

- 首页保持双面核对与原有柔光，把词级切分改为 grapheme 字素切分；“数据建模”四字分别响应，组合 emoji 与重音字符保持完整。屏幕阅读器仍读取连续原文。
- 工作区的资料、岗位、分析、计划、知识页面共用一个 240×180px 柔光反射，比首页 360×260px 更小，不引入实体圆形镜片。
- 知识页面重点强化方向卡、模式切换、筛选区、素材列表、详情的烟灰玻璃：银色上缘、暗色厚边、斜向反射、低饱和紫色选中态。背景仍为 #090a0f，字体延续 Segoe UI / Microsoft YaHei UI，正文保持实色。

```text
模式切换：紧凑玻璃分段控件
岗位方向：三张有厚度的玻璃选择卡
筛选区：一体化磨砂托盘
素材列表 / 详情：细边框与反射、清晰阅读层级
跟随柔光：跨页面复用，光线经过卡面，不遮挡点击
```

## 性能与可访问性

沿用 frontend-design、ui-ux-pro-max、vercel-react-best-practices 与 systematic-debugging 技能。先用回归测试复现“数据”绑定，再修复切分。跟随光只更新 transform 与显示状态，以 requestAnimationFrame 合并最新坐标，不逐帧读布局、不触发 React 重渲染。离开窗口、页面滚动、切换步骤时收起；触屏和减少动态效果偏好关闭光场。所有操作保留原有按钮与键盘语义，素材搜索、主题筛选和详情内容不变。

## 验收记录

- 回归测试先失败、修复后通过：原先“数据建模”切分为 `[数据, 建, 模]`，现在为 `[数, 据, 建, 模]`。组合 emoji / 重音字符完整保留，标点与换行拼接还原一致。
- 实际浏览器正面四字独立强度分别为 0.999 / 0.889 / 0.603 / 0.236，缩放分别约 1.100 / 1.089 / 1.060 / 1.024；背面“有原文支持”也分别响应。背面方向键与 Escape 可用。
- 工作区共用 1 个 240×180px 光层，实际指针坐标变化对应 transform 变化；data-visible 为 true。滚动后收起，切换步骤后复原。外层固定裁切，靠右边缘移动后页面没有横向溢出，pointer-events 为 none。
- 知识方向切换、搜索“评估”返回 2 条、打开与关闭素材详情均可操作。资料、岗位、分析、计划、知识页面均使用共享工作区光场。
- 1280px 桌面、375px 手机、320px 窄屏检查无横向溢出；手机模式切换按钮高度 44px。临时视口已恢复。
- `npm run typecheck`、`npm run build`、`npm run format:check` 通过；`node --test scripts/test_frontend_workspace.mjs scripts/test_frontend_knowledge.mjs scripts/test_frontend_events.mjs` 17 项通过；`git diff --check` 通过。
- 当前后端未启动，真实 API 联调未进行；本轮验证本地素材与前端交互。未采集硬件 FPS。触屏与系统减少动态效果仅检查实现，未切换系统设置实测。
