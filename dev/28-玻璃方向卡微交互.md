# 玻璃方向卡微交互

2026-11-23，延续已认领 Issue #37；仅本地审阅，不暂存、提交、推送。

## 设计

围绕用户喜欢的知识页三张方向卡增加交互，沿用 frontend-design、ui-ux-pro-max、vercel-react-best-practices。配色延续背景 #090a0f、正文 #f2f2f8、辅助 #a9a9bd、玻璃 #514b62、柔紫 #d5c9f9、银白 #eee4ff；字体延续 Segoe UI / Microsoft YaHei UI。三列左对齐、内容与按钮语义不变。

```text
           鼠标经过：一张卡轻微倾斜，斜向反射滑过表面
[ AI 产品经理 ] [ 全栈开发 ] [ Agent 开发 ]
      ━━━━━━━━━  选择时底缘银光移动到目标卡
           点击 / 键盘确认：柔和压下与小幅回弹
```

只在当前卡上回应输入，不新增自动循环、颗粒或悬浮提示。最大倾角约 2.4°，保持文字清晰。只增强这一组选择控件，不扩展到其它未批准的改进。

本地和在线共用 RolePicker，防止两种模式手感不一致；选择仍立即更新，不等待动画。指针位置使用 ref 与 requestAnimationFrame，缓存未变换的卡片几何；动画只改 transform / scale / opacity。离开、滚动、窗口失焦、尺寸改变时复原。触屏不倾斜；减少动态效果时取消位移与回弹，保留静态选中边缘和键盘焦点。

## 验收

- 三张卡本地 / 在线共用 RolePicker，原有素材数量 5 / 6 / 9 和选择行为保持；在线登录提示与业务请求逻辑不变。
- 实际鼠标从全栈卡左上移动到右下，倾角由 X 1.53° / Y -1.66° 变为 X -0.90° / Y 1.50°，反光位移由 -22.13% 变为 20.04%，单次仅当前卡生效。
- 点击后正常切换至 6 份素材；键盘 Enter 可选 Agent，结果变为 9 份；键盘操作清除鼠标倾斜，hover 卡数量为 0。滚动后同样复原。
- 选中底缘银光使用 CSS transform 过渡；桌面最终卡片与银光 X 坐标分别 907.375 / 907.365。320px 窄屏分别 109.552 / 109.552，宽度均 85.552px。375px / 320px 无横向溢出，临时视口已复原。
- 点击回弹采用 360ms Web Animation，触屏也可直接选择；动画不阻塞业务更新。减少动态效果 / 粗指针退化由媒体查询与事件入口判断；未切换系统设置或在真实手机硬件验证。未采集精确 FPS。
- `npm run typecheck`、`npm run build`、`npm run format:check`、17 项现有前端回归测试、`git diff --check` 通过。
