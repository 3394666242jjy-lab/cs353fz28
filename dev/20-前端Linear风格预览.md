## 视觉方向与取舍

以 Linear 应用工作区的克制层级为参考：石墨黑画布、微亮面板、细分隔线、紧凑导航与小范围紫色强调。保持 CareerPilot 的资料—岗位—证据—计划流程，让公共学习参考与个人经历证据在内容上仍然清楚。

主要颜色：画布 `#101114`、导航 `#141518`、面板 `#191a1f`、边界 `#2b2d35`、正文 `#eeeff3`、主要操作 `#6555d6`；链接和焦点用较浅紫色 `#b3adff`。次级文字为 `#999ba9`。按钮与链接分别用填充色和文本色，避免浅紫色按钮配白字的对比不足。

字体使用系统 Segoe UI Variable / Segoe UI，中文回退 Microsoft YaHei UI / PingFang SC；页面标题 30px，节标题 16px，主要内容 12–14px。保留现有系统字体路径，无需下载字体或新增依赖。

布局方案：

```text
固定导航 224px │ 面包屑与账号
              │ 简短页面标题与用途说明
              │ 资料：四步路径 + 上传/样例双栏
              │ 知识：模式标签 + 岗位筛选 + 列表/阅读双栏
              │ 分析：结论列表 + 原文证据
```

设计自审：求职准备是持续使用的工作区，首屏应突出可操作的资料流程。移除原有装饰插画、缩短宣传式标题；知识素材采用连续列表，减少重复边框卡片。紫色用于主要操作与选中状态，状态色继续区分成功、警告和故障。

## 变更

- 紧凑导航、图标面包屑、较短页面标题，保留现有导航功能。
- 上传使用可访问的原生文件输入，包装为统一的文件选择区域，继续使用原有选择/校验/上传处理。
- 知识页模式使用底边标签；列表与阅读面板显示当前选择；键盘焦点在列表内部可见。
- 适配手机单列、横向导航和表单；保留 reduced-motion 规则。
