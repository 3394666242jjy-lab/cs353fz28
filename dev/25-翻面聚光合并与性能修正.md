# 翻面聚光合并与性能修正

2026-11-22，延续已认领 Issue #37。本轮按用户选择，把 B 翻面核对与 C 正面聚光阅读合成默认首页交互；继续本地审阅，不提交或上传。

## 实现前设计

沿用烟灰玻璃、双层边缘、内侧高光。颜色与字体沿用上一轮：#090a0f、#f2f2f8、#b3b3c5、#c8b6ff、#ffffff24；Segoe UI / Microsoft YaHei UI。原文和结论保持横排。

- 原文正面：局部放大阅读；镜片从桌面直径 156px 缩到 96px，窄屏从 130px 缩到 80px。只在交互时出现。
- 镜片默认偏向指针侧上方，并保持在卡片内；取样点单独跟随指针，可到达 0–100% 边界，解决左上角无法对准的问题。
- 正文不随鼠标改变布局。镜片与放大的文字副本只做 translate3d / scale；每帧最多更新一次，使用最新坐标，不叠加位置过渡。
- 移动镜片时暂停整块玻璃反光更新，避免大面积渐变绘制与局部阅读争用。
- “翻面核对 / 翻回原文”用独立明确按钮，避免在触屏阅读或选择文字时意外翻面；原文区域支持方向键移动、Enter 翻面和 Escape 收起镜片。翻面背面只显示分析，不显示镜片。
- 默认首页直接展示合并方案，不再让用户在 A/B/C 中切换；保留完整原文弹层。

自审：镜片位置与取样位置分开，既不挡住指针，也不牺牲边缘文字；缩小光圈同时增加局部放大倍率到 1.3。避免把“顺滑”处理成滞后的追随动画。

实现调整：镜片偏移随取样点在两轴上连续变化，靠边时向内偏移，不使用跨阈值跳到另一侧的逻辑。移动到中央时镜片可与指针局部重合；边缘原文取样仍覆盖 0–100%。

## 已实现

- 默认首页统一为翻面 + 正面聚光阅读，移除 A/B/C 对比控制和退役方案代码。旧 `?hero=` 链接仍打开同一合并页面。
- GlassReader 独立处理聚光，桌面外径 96px、阅读区宽度不超过 360px 时为 80px；倍率 1.3。未交互、离开、滚动、切换片段、翻面时收起镜片。
- 位置使用一个 requestAnimationFrame 合并最新输入，不取消并重建每个事件帧；只更新镜片和预先绘制的原文副本的 translate3d/scale。静态圆形 overflow 裁切代替逐帧 clip-path/transform-origin；尺寸变化时更新副本尺寸，边界通过 ResizeObserver 与滚动监听失效。
- 阅读区域内的指针移动不会同时更新整卡片的大面积反光渐变。镜片无位置 transition，消除原 100ms 过渡反复追赶目标的拖尾。
- 独立翻面按钮保留 680ms 动效，方向键阅读、Enter 翻面、Escape 收起镜片；翻面期间阻止重复触发，焦点保留在按钮。正反面用 inert 隔离不可见内容。
- 沿用完整原文弹层与文件/版本/行号定位，换片段时自动回到正面。

## 验证结果

- `cd frontend && npm run typecheck && npm run build && npm run format:check`：全部通过；61 个模块，CSS 73.83 kB、JS 342.70 kB。
- `node --test scripts/test_frontend_workspace.mjs scripts/test_frontend_knowledge.mjs scripts/test_frontend_events.mjs`：16 项通过。新增 2 项覆盖四角取样、镜片不越界、外部指针钳制、内部移动连续性、缩放映射中心正确。
- `git diff --check`：通过。
- 浏览器桌面：96px 镜片；左上角实际取样成功，镜片不覆盖该角落指针且完整保留在卡片内；横向拖动到右侧不误翻面；检查确认镜片没有 clip-path 与位置 transition（duration 0s）。
- 浏览器键盘：方向键移动、Enter 翻面、翻回、切换片段回正面；背面收起镜片且前面 inert；原文弹层 Escape 关闭并恢复入口焦点。
- 391px 手机与 320px 窄屏：80px 镜片；正文 scrollHeight 与阅读区高度一致，无横向溢出。检查了视口变化后重新进入阅读区域的边界更新。临时视口已恢复，默认首页预览已保留。

验证限制：没有采集 GPU 帧时间或精确 FPS，不能保证所有硬件的帧率；本次验证了交互结果与绘制方式，最终拖动手感仍需用户在本机体验。触屏指针捕获与纵向滚动保护已实现，未使用真实手机硬件测试；未更改系统减少动态效果设置。真实后端联调不在本轮范围。
