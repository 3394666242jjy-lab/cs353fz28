# 前端 M3：知识素材预览与工作台改版

2026-11-18，Refs #36，Refs #37。

> 2026-11-20 更新：后续已增加在线知识查询消费端，见 [M3.2 在线知识查询验收](19-前端M3在线知识查询验收.md)。本文保留 11 月 18 日本地预览改版的验收记录；在线端到端仍待后端 #42 部署后联调。

## 本周要完成什么

负责人在 11 月 13 日调整了 M3 主线，当前应以 [M3 核心计划](16-M3核心架构与实施计划-m3-core.md) 为准：先补强 Agent、结构化切分和三方向知识底座，任务看板与文本面试后移。PR #35 已合入 M3.1 基线；在线知识入库、双通道检索/输出和原生 checkpoint 迁移属于后续 M3.2，不能将本次前端预览描述为在线 RAG 已接通。

前端本次交付是把已有知识来源变成可浏览、可筛选、可追溯的阅读界面，并改善求职准备工作台。个人匹配仍由个人原文证据支持，公共知识只作学习参考。

## 实现

- 新增“知识素材”入口，直接读取 `knowledge/sources.json` 和 `knowledge/cards/*.md`，不复制维护另一份目录。三方向为 AI 产品经理、全栈开发、Agent 开发，分别有 5、6、9 份素材，共 13 个独立来源。
- 方向、主题和关键词组合过滤；多个空白分隔的关键词同时匹配标题、主题或摘要。提供结果数量、空结果提示和清空筛选。
- 详情展示完整知识要点、适用边界、摘要版本、来源核验日期、适用版本和官方链接；明确区分项目整理摘要与官方原文。
- 桌面采用深色导航、浅色内容区、蓝色操作按钮和列表/阅读双栏；窄屏改为横向导航与单栏阅读。详情支持键盘打开，窄屏选择素材后聚焦到阅读区。
- 登录表单收纳到账号按钮，首页突出资料、岗位、分析、计划四步路径；统一资料、证据和计划样式。样例确认提示明确“未保存到后端”。

未改变业务 API、数据库、鉴权或 SSE 协议；未新增 npm 依赖。知识摘要随前端构建打包，更新素材后需重新构建。

## 验证

在 `frontend/` 执行，均通过：

```text
npm run typecheck
npm run build
npm run format:check
```

生产构建为 50 个模块，CSS 31.37 kB、JS 314.61 kB（构建时输出，未提交 dist）。沙箱内 Vite 启动子进程报 `spawn EPERM`，获准在沙箱外重跑后构建成功。`git diff --check` 通过。

浏览器手工验证：

| 场景 | 结果 |
| --- | --- |
| 三方向目录 | AI 产品经理 5、全栈 6、Agent 9 |
| 全栈搜索 `Fetch HTTP` | 命中 1 份，详情内容、边界、版本、日期和 MDN 来源地址完整 |
| Agent 搜索无匹配词 → 清空筛选 | 0 份并显示提示；重置后恢复 9 份 |
| Agent 按 MCP 主题筛选 | 1 份；Enter 打开详情，窄屏焦点位于“素材详情” |
| 样例 JD → 固定样例分析 → 原文证据 | 可查看 project-demo.md、v1、行号与引用文本 |
| 样例计划草稿 → 确认 | 展示任务，确认按钮进入已确认状态 |
| 宽屏与窄屏 | 实测 CSS viewport 2266px、1440×900px 与 391×844px；首页、知识详情均无横向溢出 |

窄屏使用浏览器 viewport 覆盖，并以 DOM 实际尺寸核对（浏览器原有缩放会影响请求尺寸与 CSS 尺寸的换算），验收后恢复默认尺寸。截图裁去了浏览器捕获范围之外的空白。本次未连接后端，真实账号登录、资料上传、分析执行、SSE 重连与服务端计划保存未重新实测；样例验证不能替代后端集成验收。外部来源链接已核对 href，未声称逐个链接在线可达。
