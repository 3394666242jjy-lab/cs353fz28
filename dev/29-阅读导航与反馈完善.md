# 阅读、导航与反馈完善

2026-11-23，用户批准八个方面全部实现。延续已认领 Issue #37，仅本地修改，待用户审阅后再决定提交。

## 设计方案

继续使用 frontend-design、ui-ux-pro-max、vercel-react-best-practices：背景 #090a0f、正文 #f2f2f8、辅助 #c5c5d4、银白 #eee4ff、柔紫 #d5c9f9、烟灰 #514b62；字体 Segoe UI / Microsoft YaHei UI。左对齐，内容阅读面比导航玻璃更沉稳。动效只回应选中、展开和完成，不增加循环装饰。

```text
明确首页入口 + 导航选中底板移动
  ↓
方向卡 / 搜索词与主题标签 → 素材列表高光 → 详情短过渡
                                           ↓
                                   专注阅读玻璃面板
                                   来源信息按需展开
  离开后返回：恢复方向、搜索、素材与位置
```

1. 素材与详情联动：即时切换、短暂淡入，连续选择只显示最新素材。
2. 专注阅读：原生模态弹层、明确关闭、Escape、焦点返回与原位置保留。
3. 导航：移动玻璃底板、内容短过渡、明确首页入口，浏览器前进后退正确。
4. 进度记忆：版本化会话存储、按账号隔离、保存方向 / 搜索 / 素材 / 滚动位置。
5. 搜索：可移除关键词与主题标签，字面命中高亮与清空筛选。
6. 来源：紧凑来源区，版本、日期、适用范围按需展开。
7. 反馈：真实保存 / 上传成功后的按钮确认或行内完成标记，保留原地重试，不伪造成功。
8. 阅读与性能：正文与辅助字号、可见焦点、降低多层模糊，提供轻量效果设置并尊重系统减少动态效果。

## 验收记录

- 素材联动：选中条目立即高亮，详情按素材 ID 190ms 短过渡；连续选择以最新 React 状态为准，没有延迟计时器覆盖新选择。
- 专注阅读：实际打开、来源展开、Escape / 按钮退出均可用；退出焦点返回“专注阅读”。补充显式 Tab 边界循环，实测首按钮 Shift+Tab 到最后来源链接，来源链接 Tab 回首按钮，焦点保持弹层内。
- 进度记忆：按 owner 分开的 v1 sessionStorage，仅记录方向、筛选、素材 ID 与位置。离开知识页再浏览器返回，原 React 搜索、全栈方向、选中素材恢复；阅读 Y 坐标实测 970.6667 → 970.6667。点击导航引发的滚动不再覆盖上次阅读位置。刷新同样恢复已选素材。
- 导航：首页明确入口可用，侧栏玻璃底板使用当前按钮真实 offset，横纵布局共用；浏览器前进 / 后退分别恢复岗位 / 知识页。动画不重挂载正在运行的分析表单。
- 搜索：关键词标签移除、主题标签移除、清空筛选、React 标题 / 主题 / 正文命中高亮均验收；C++ / [API] 等按字面匹配，合并重叠命中且保留完整原文。
- 来源：本地详情与专注阅读共用版本 / 日期 / 适用范围折叠区；在线结果接入相同来源组件并保留 http / https 校验。
- 反馈：本地样例保存出现“✓ 本地样例已保存”；独立模拟 API 成功创建岗位后出现“✓ 岗位已保存”。上传使用无个人信息的 synthetic-upload.md，本地模拟第一次失败后原地重试，最终出现解析完成勾选与可使用状态。模拟端口 8011 / 5175，与主预览 5174 隔离。
- 附带修复：模拟验收发现，解析重试期间切页后，资料列表的滞后 failed 快照会丢弃 retryExecutionId；新 reconcileDocumentSnapshot 保留进行中的执行直到 ready / 轮询终态，增加回归测试。
- 性能：轻量效果开关实测 data-effects=light，跟随光 display:none、详情 backdrop-filter:none；恢复开关可继续正常效果。指针动画 ref / rAF，不添加动效依赖。低核心设备默认轻量，可手动切换。
- 阅读正文桌面 15px、手机 16px，辅助信息 12px；375px / 320px 弹层实测无横向溢出，320px 弹层宽 286px、内部 scrollWidth 269px。手机返回列表焦点回选中素材。临时视口已恢复。
- `npm run typecheck`、`npm run build`、`npm run format:check`、20 项前端回归测试、`git diff --check` 通过。

边界：未进行真实后端联调或真实账号测试；上传 / 保存端到端只用隔离模拟服务。未使用真实手机或屏幕阅读器，未切换系统减少动态效果设置，未采集硬件 FPS。浏览器日志中两个旧 duplicate-key 错误时间戳为 06:19:07，已删除当时冲突的过渡节点；之后复测无新增同类日志。
