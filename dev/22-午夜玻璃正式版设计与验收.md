# 午夜玻璃：正式页面设计

2026-11-22，Refs #37。用户已选择 C 光效，要求更高透明度、齐整布局、Apple 式有趣微交互与图中景深特写。本轮实现正式前端页面，本地审阅后才上传，不提交或推送。

## 实现前设计

- 六个主色：夜幕 #090a0f、玻璃 #ffffff0b、银白 #f2f2f8、次级 #b3b3c5、雾紫 #c8b6ff、边缘 #ffffff24。低透明填充叠加边缘高光，背后光场可透见；正文区增加深色底，保证对比。
- 字体：Segoe UI Variable / Segoe UI，中文 Microsoft YaHei UI / PingFang SC；首页 56–68px 展示标题，工作区 28px 标题、13–14px 正文。主要内容左对齐。
- 首页是“短文案 / 可交互景深特写”，下方承接一组整齐的准备入口。正式工作区复用现有上传、分析、计划、知识业务组件。
- 特写使用 SVG 与 CSS 生成焦外光点，跟随“经历 / 证据 / 行动”选择改变聚焦对象；交互卡片可展开为原文特写。鼠标轻微视差与局部光泽，触屏有点击等价入口。关闭、Escape、焦点恢复与 reduced-motion 降级必须可用。
- 动效：选择时共享滑块，卡片倾斜幅度很小；聚焦切换在 220–450ms 内完成。背景无持续大范围移动，减少读写干扰。

```text
首页：品牌 / 知识入口 / 进入工作区
      左：短标题与两个行动入口 │ 右：景深光点 + 透明玻璃原文特写
      下：三步交互讲解与实际工作区入口
工作区：紧凑导航 │ 玻璃顶栏、资料/岗位/分析/计划/知识实际组件
```

自审取舍：采用用户指定的玻璃与景深语言，避免将示意光点当作个人评分。所有个人信息预览使用仓库现有合成样例，标记清楚；光点只作视觉构成，没有假统计。冗余首页路径、重复账号入口、技术状态首屏提示收起，必要文件限制与证据边界仍在操作处保留。

## 已实现

- `/` 为正式首页；`/?view=workspace&step=0` 为真实工作区。首页入口接入现有资料、分析、计划、知识组件，浏览器前进、后退与刷新恢复当前工作区页面。
- 独立渐变细边与低透明度面板填充（约 5%–14%），叠加 26px 背景模糊、银紫光场、微噪点；描边不再向玻璃内部填充不透明底色。
- SVG 景深点阵随三段视角切换改变聚焦，鼠标轻微视差与局部光泽，共享滑块、按钮按压、示例文件叠片展开。触屏可使用相同的点击入口。
- 原文特写支持两个合成片段、文件版本和行号；支持 Escape、点击背景关闭、Tab/Shift+Tab 循环与关闭后焦点恢复。弹层打开时锁定页面滚动。
- 工作区同步采用玻璃视觉，移除重复入口、重复文件名和技术性首屏提示。开发诊断与 PDF 限制改为按需展开。
- 旧的三方向演示仅在开发模式通过 `?design=aurora|orbital|glass` 加载，生产构建使用正式页面。
