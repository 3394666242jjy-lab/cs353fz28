# 校园设备借用系统项目说明

本文全部为合成数据，仅用于开发联调。描述的项目没有真实用户、上线地址或实验结果。

## 项目背景

为学生查询设备、提交借用申请和记录归还状态提供一个 Web 应用。

## 数据库设计工作

负责设计设备、借用申请和归还记录的数据模型，定义字段、关联关系及查询索引，并绘制数据库关系图。

## 查询缓存工作

在热门设备列表查询中使用 Redis 缓存查询结果，减少重复访问 MongoDB。
本资料未提供延迟、吞吐量或缓存命中率的测量记录。

## 接口与协作

使用 FastAPI 编写设备列表与借用申请接口，通过 Git 分支提交修改并参与代码审查。
